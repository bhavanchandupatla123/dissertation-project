# Methodology

## 1. Data collection and integration

The project combined multiple public socio-economic datasets covering areas including:

- Educational attainment
- Employment status
- Poverty conditions
- Self-employment income

The datasets were brought together into a single analytical framework so that relationships across the variables could be explored consistently.

## 2. Data preparation

Before modelling, the workflow focused on data quality and reproducibility:

- Checked and treated missing values
- Identified duplicate records
- Investigated outliers
- Standardised variables where appropriate
- Validated the integrated dataset before analysis

## 3. Exploratory Data Analysis

EDA was used to understand the structure of the data and identify useful predictive relationships.

Techniques included:

- Descriptive statistics
- Distribution analysis
- Correlation analysis
- Trend identification
- Anomaly detection
- Feature-importance interpretation

## 4. Model development

The project applied supervised machine-learning techniques including:

- Random Forest
- Gradient Boosting
- Decision Tree
- Regression-based modelling

Cross-validation was used as part of the model-development process to reduce overfitting and assess generalisability.

## 5. Model evaluation

### Classification

Models were compared using:

- Accuracy
- Precision
- Recall
- F1 score
- ROC / AUC

### Regression

Regression performance was assessed using:

- R²
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)

## 6. Interpretation and responsible analytics

The final stage focused on translating model outputs into understandable findings while considering:

- Privacy
- Fairness
- Transparency
- Bias
- Explainability
- Reliability
- The continued role of human judgement in automated decision support

The overall aim was to produce technically sound results that could also be interpreted by non-technical decision-makers.
