# Model Results

## Classification performance

### Gradient Boosting

- Classification accuracy: **96%**
- ROC AUC: **0.99**

Gradient Boosting was the strongest-performing classification model in the reported comparison.

### Random Forest

- Classification accuracy: **92%**

Random Forest also performed strongly, but Gradient Boosting achieved the better reported classification result.

## Regression performance

### Decision Tree Regression

- R²: **0.82**
- MAE: **0.04**
- RMSE: **0.21**

The reported R² indicates that the Decision Tree regression model explained approximately 82% of the variance in the target variable.

## Interpretation

The comparison demonstrated the value of evaluating multiple approaches rather than selecting a model based on complexity alone. The project used structured performance metrics to identify the strongest models and then interpreted their outputs within the wider labour-market context.

## Practical takeaway

The modelling stage reinforced three important analytical principles:

1. Reliable predictions depend on strong data preparation.
2. Model choice should be based on evidence from appropriate evaluation metrics.
3. Technical performance should be considered alongside explainability, robustness and responsible use.
